## Turn this repo into a website (GitHub Pages)

1. Open https://github.com/CJD0314/the-tape
2. Click **Settings**.
3. Left sidebar: **Pages**.
4. Build and deployment:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save. Wait 1–2 minutes.
6. Site:
   https://cjd0314.github.io/the-tape/

That URL is not The Split.

## Update command

When the user says **tape update**: lock `tape-ledger.json` first, close yesterday, board today, push `CJD0314/the-tape` main.
